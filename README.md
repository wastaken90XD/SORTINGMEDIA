# Magnus

**An app for sorting media of any kind.**

Magnus is a powerful, automation-ready media organizer for images, videos, and other files. It combines fast browsing, tagging, filtering, grouping, metadata tools, gesture controls, macros, and rule-based organization in one focused workspace.

The app is designed for people who want precise control today while leaving room for increasingly automated media organization tomorrow.

## Build

The Android application remains on the stable `com.mediasorter` application ID so existing installs and their saved settings continue to work. The user-facing product name is **Magnus**.

```text
gradle :app:assembleRelease
```
